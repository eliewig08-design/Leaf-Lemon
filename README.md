# Leaf & Lemon

A responsive salad food truck website concept for San Luis Obispo and Cal Poly students.

## Open the website

Open `index.html` in a browser. There is no installation or build step. Salad and drink images are embedded; Google Fonts requires internet access.

## Features

- Eight signature salads and a build-your-own bowl
- Custom greens, toppings, proteins, dressings, drinks and double protein
- Itemized live pricing
- Demo checkout and feedback pages
- Responsive phone and desktop layouts

## Editing together

Edit `index.html` directly or open the repository in your preferred editor. Repository owners can invite teammates under Settings → Collaborators. Commit changes to keep the shared copy current.

## Preview limitations

Checkout and feedback are demonstrations. They do not send orders, collect payments, reserve pickup, or save reviews. Food and drink images are AI-generated illustrations. Menu pricing and business operations are illustrative.

## Hosting

For GitHub Pages, use the main branch and root directory as the publishing source. This repository is the source of the website; enabling hosting is a separate step.
